# Транскрибатор для Android

Распознавание речи прямо на телефоне (whisper.cpp) и сборка документов через Claude — мобильная версия настольного транскрибатора.

- Входные форматы: всё, что декодирует Android — mp3, m4a/aac, wav, ogg/opus, flac, amr, mp4, mkv/webm, 3gp, mov (H.264/H.265).
- Транскрипт: TXT, SRT, VTT, JSON.
- Режимы с Claude (инструкция, конспект, протокол): через API-ключ или вручную (скопировать промпт → вставить ответ). Скриншоты из видео к разделам, экспорт Word / Markdown / HTML / ZIP.

APK собирается GitHub Actions (вкладка Actions → последний запуск → артефакт `Transcriber-apk`).
